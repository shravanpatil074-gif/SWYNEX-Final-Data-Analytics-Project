# SWYNEX Final Data Analytics Project – Titanic Survival Analysis

## 1. Project Overview
This project analyzes the Titanic passenger dataset to understand the factors associated with passenger survival. The project combines data cleaning, exploratory data analysis, KPI preparation, an interactive Excel dashboard, and business-style insights.

## 2. Problem Statement
Analyze the Titanic passenger dataset to identify demographic and travel-related patterns associated with survival and communicate the findings through an interactive dashboard.

## 3. Dataset
- Records: 891
- Main outcome: `Survived`
- Key dimensions: gender, passenger class, age group, embarkation point, and family group
- Tool: Microsoft Excel

## 4. Data Cleaning
The dataset was checked and prepared for analysis by:
- Checking missing values
- Standardizing missing/unknown categories
- Checking duplicate records
- Standardizing data types
- Creating readable labels for survival status, passenger class, embarkation and age groups
- Creating family-size and family-group categories

Final dataset checks:
- Rows: 891
- Duplicate rows: 0
- Missing Age after preparation: 0
- Missing Embarked after preparation: 0

## 5. Analysis Performed
The project analyzes:
1. Survival by gender
2. Survival by passenger class
3. Survival by age group
4. Survival by embarkation point
5. Survival by family group
6. Overall survival KPIs

## 6. Key Findings
- Overall survival rate: **38.4%** (342 of 891 passengers).
- Female survival rate: **73.9%**.
- Male survival rate: **19.1%**.
- 1st Class survival rate: **63.0%**.
- 3rd Class survival rate: **24.2%**.
- Highest embarkation survival rate: **Cherbourg (C), 55.4%**.
- Highest family-group survival rate: **Small (2-4), 57.9%**.

## 9. Conclusion
The analysis shows that survival was strongly associated with passenger gender and class, while age, embarkation point and family group also showed meaningful differences. The dashboard makes these patterns easier to explore and communicate.
